introduction

Overview

The H10-W SDK internally uses FAST-DDS as middleware to communicate with the main controller, implementing functional calls for user convenience. It supports both C++ and Python programming languages, multiple robot models, and simultaneous connection to multiple robots. Under different robot models, it categorizes functional modules such as parameters, motion, and system, allowing users to quickly find the interfaces they want to use.

Coordinate System Definition

  • World Coordinate System: Establish the world coordinate system with the projection point of the robot’s geometric center on the ground at startup as the origin. The positive x-axis points forward, the positive y-axis points left, and the positive z-axis is opposite to the direction of gravity, with the x, y, and z axes following the right-hand rule.

  • Robot Coordinate System: Establish the robot coordinate system with the robot’s geometric center as the origin. The positive x-axis points forward, the positive y-axis points left, and the positive z-axis is opposite to the direction of gravity, with the x, y, and z axes following the right-hand rule.
