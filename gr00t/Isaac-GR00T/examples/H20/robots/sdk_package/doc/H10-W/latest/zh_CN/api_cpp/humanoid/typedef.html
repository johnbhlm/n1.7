类型别名

humanoid::JointTarget

using humanoid::JointTarget = std::tuple<uint32_t, double>

表示关节运动目标的类型别名

  • tuple_element 0: 关节索引（范围:参考枚举JointIndex)

  • tuple_element 1: 目标关节位置

humanoid::JointLimit

using humanoid::JointLimit = std::vector<std::tuple<uint32_t, double, double>>

表示关节限位参数的类型别名

  • tuple_element 0: 关节索引（范围:参考枚举JointIndex)

  • tuple_element 1: 最大关节位置

  • tuple_element 2: 最小关节位置

humanoid::JointMaxAcc

using humanoid::JointMaxAcc = std::vector<std::tuple<uint32_t, double>>

表示关节最大加速度的类型别名

  • tuple_element 0: 关节索引（范围:参考枚举JointIndex)

  • tuple_element 1: 最大关节加速度

humanoid::JointMaxVel

using humanoid::JointMaxVel = std::vector<std::tuple<uint32_t, double>>

表示关节最大速度的类型别名

  • tuple_element 0: 关节索引（范围:参考枚举JointIndex)

  • tuple_element 1: 最大关节速度

humanoid::CartTransMaxAcc

using humanoid::CartTransMaxAcc = std::vector<std::tuple<uint32_t, double>>

表示笛卡尔平移最大加速度的类型别名

  • tuple_element 0: 笛卡尔坐标系索引

  • tuple_element 1: 最大笛卡尔平移加速度

humanoid::CartTransMaxVel

using humanoid::CartTransMaxVel = std::vector<std::tuple<uint32_t, double>>

  • tuple_element 0: 笛卡尔坐标系索引

  • tuple_element 1: 最大笛卡尔平移速度

using humanoid::CartRotaMaxAcc = std::vector<std::tuple<uint32_t, double>>

表示笛卡尔旋转最大加速度的类型别名

  • tuple_element 0: 笛卡尔坐标系索引

  • tuple_element 1: 最大笛卡尔旋转加速度

humanoid::CartRotaMaxVel

using humanoid::CartRotaMaxVel = std::vector<std::tuple<uint32_t, double>>

表示笛卡尔旋转最大速度的类型别名

  • tuple_element 0: 笛卡尔坐标系索引

  • tuple_element 1: 最大笛卡尔旋转速度

humanoid::TcpOffsetParams

using humanoid::TcpOffsetParams = std::vector<std::tuple<int32_t, std::vector<double>>>

表示TCP工具坐标系偏移参数的类型别名

  • tuple_element 0: 笛卡尔索引

  • tuple_element 1: 偏移参数

humanoid::TcpPayloadParams

using humanoid::TcpPayloadParams = std::vector<std::tuple<int32_t, std::vector<double>>>

表示TCP负载参数的类型别名

  • tuple_element 0: 笛卡尔索引

  • tuple_element 1: 负载参数

humanoid::JointControlParams

using humanoid::JointControlParams = std::vector<std::tuple<uint32_t, double, double, double>>

表示关节控制参数的类型别名

  • tuple_element 0: 关节索引

  • tuple_element 1: kp参数

  • tuple_element 2: kd参数

  • tuple_element 3: kpv参数

humanoid::CartesianControlParams

using humanoid::CartesianControlParams = std::vector<std::tuple<uint32_t, std::array<double, 6>, std::array<double, 6>, std::array<double, 6>>>

表示笛卡尔控制参数的类型别名

  • tuple_element 0: 笛卡尔坐标系索引

  • tuple_element 1: kp参数数组(6个元素)

  • tuple_element 2: kd参数数组(6个元素)

  • tuple_element 3: kpv参数数组(6个元素)
