结构体

RealtimeJointsParams

class humanoid_sdk_py.h10w.RealtimeJointsParams

实时指令关节运动控制参数结构体

字段说明:

  • left_arm: 左臂 7 个关节角（rad）

  • left_arm_valid: 左臂数据有效性，1-执行，0-保持

  • right_arm: 右臂 7 个关节角（rad）

  • right_arm_valid: 右臂数据有效性

  • torso: 躯干 3 个关节角（rad）

  • torso_valid: 躯干数据有效性

  • time: 运动控制周期（秒）

RealtimeTcpParams

class humanoid_sdk_py.h10w.RealtimeTcpParams

实时指令末端位姿运动控制参数结构体

字段说明:

  • left_arm: 左臂末端位姿 (x, y, z, rx, ry, rz) (m, rad)

  • left_arm_valid: 左臂数据有效性，1-执行，0-保持

  • right_arm: 右臂末端位姿 (x, y, z, rx, ry, rz) (m, rad)

  • right_arm_valid: 右臂数据有效性

  • torso: 躯干末端位姿 (x, y, z, rx, ry, rz) (m, rad)

  • torso_valid: 躯干数据有效性

  • time: 运动控制周期（秒）

LinearTarget

class humanoid_sdk_py.h10w.LinearTarget

末端直线运动控制参数结构体

字段说明:

  • type: CartIndex枚举类型，1-左臂 2-右臂 3-躯干

  • pose: 6维数组 [x, y, z, rx, ry, rz]（位置和旋转）

  • velocityPercent: 速度百分比 (0-1]

  • accelerationPercent: 加速度百分比 (0-1]

TcpPoseParams

class humanoid_sdk_py.h10w.TcpPoseParams

末端位姿参数结构体

字段说明:

  • type: CartIndex枚举类型，1-左臂 2-右臂 3-躯干

  • pose: 6维数组 [x, y, z, rx, ry, rz]（位置和旋转）

MoveMessageParams

class humanoid_sdk_py.h10w.MoveMessageParams

运动状态参数结构体

字段说明:

  • state: 运动状态，0-Idle 1-Running 2-Paused 3-Error

  • position: 位置向量

  • velocity: 速度向量

  • tcp_pose: TCP位姿参数向量

  • task_id: 指令任务 ID，标识当前正在执行的指令

ErrorMessageParams

class humanoid_sdk_py.h10w.ErrorMessageParams

错误信息参数结构体

字段说明:

  • id: 错误ID

  • level: 错误级别

  • module: 错误模块级别，1-算法模块 2-控制器模块 3-驱动模块 4-固件模块

  • error_code: 错误代码

  • msg: 错误消息

JointMotorCmd

class humanoid_sdk_py.h10w.JointMotorCmd

电机控制命令结构体

字段说明:

  • mode: 控制模式，0-禁用控模式 1-启用模式

  • op_mode: 工作模式，0-力位混控模式（臂+头部） 1-同步位置控制模式（升降机构）

  • q: 位置（弧度）

  • dq: 速度（弧度/秒）

  • tau: 关节前反馈力矩（牛·米）

  • kp: 关节刚度系数

  • kd: 关节阻尼系数

  • reserved: 保留字段

WheelMotorCmd

class humanoid_sdk_py.h10w.WheelMotorCmd

轮电机运动控制命令结构体

字段说明:

  • mode: 控制模式，0-禁用模式 1-启用模式

  • op_mode: 工作模式，2-同步速度模式

  • v: 轮线速度，单位 m/s

  • reserved: 保留字段

JointMotorState

class humanoid_sdk_py.h10w.JointMotorState

电机状态结构体

字段说明:

  • mode: 控制模式，0-禁用模式 1-启用模式

  • op_mode: 工作模式，0-力位混控模式（臂+头部） 1-同步位置控制模式（升降机构）

  • q: 位置（弧度）

  • dq: 速度（弧度/秒）

  • ddq: 加速度（弧度/秒²）

  • cur: 电流（安培）

  • vol: 电压（伏特）

  • tau_est: 关节前反馈力矩（牛·米）

  • temp: 温度（摄氏度）

  • kp: 关节刚度系数

  • kd: 关节阻尼系数

  • enable_state: 使能状态,1：使能，0：失能

  • error_code: 错误码

  • warning_code: 警告码

  • reserved: 保留字段

PCUState

class humanoid_sdk_py.h10w.PCUState

PCU状态结构体

字段说明:

  • power_state: 上电状态，0-待机状态 1-软起状态 2-上电状态 3-下电状态 4-错误状态

  • bumper_switch_state: 触边开关状态 0：碰撞，1：安全

  • emergency_stop_state: 急停，0：急停，1：安全

  • soft_emergency_stop_state: 软急停，0：软急停，1：安全

  • error_code: 错误码

  • warning_code: 警告码

EnableState

class humanoid_sdk_py.h10w.EnableState

使能状态结构体

字段说明:

  • upper_enable_state: 上半身使能状态，0：全部失能，1：全部使能，2：部分使能

  • base_enable_state: 电底盘使能状态，0：失能、1：使能

LowState

class humanoid_sdk_py.h10w.LowState

H10W底层状态结构体

字段说明:

  • version: 版本号

  • tick: 时间戳（滴答数）

  • data_valid: 数据有效标志，0：全部无效，1：部分有效，2：全部有效

  • joint_motor_state: 全身电机状态

  • wheel_motor_state: 轮电机状态

  • imu_state: IMU状态

  • pcu_state: 电源控制单元状态

  • enable_state: 使能状态

  • time_seconds: 累计时间，单位：s

  • error_code: 错误码

  • warning_code: 警告码

  • reserved: 保留字段
