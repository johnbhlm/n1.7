humanoid::h10w::LRCUCmd
--------------------------------------
.. doxygenstruct:: humanoid::h10w::LRCUCmd
   :members:
   :protected-members:
   :private-members:
   :undoc-members:

.. admonition:: 参数说明
   :class: note

   - **mode**：灯环使能控制

     - 0：disable（禁用）
     - 1：enable（启用）

   - **led_r**：RGB-R 通道亮度

     - 范围：0~255
     - 0：最暗，255：最亮

   - **led_g**：RGB-G 通道亮度

     - 范围：0~255
     - 0：最暗，255：最亮

   - **led_b**：RGB-B 通道亮度

     - 范围：0~255
     - 0：最暗，255：最亮

   - **led_mode**：LED 模式

     - 0：常闭（off）
     - 1：常亮（constant）
     - 2：闪烁（blink）
     - 3：呼吸（breathing）
     - 4：眨眼（wink）
     - 5：左闪（left flash）
     - 6：右闪（right flash）
     - 7：前闪（front flash）
     - 8：后闪（rear flash）

   - **led_frequency**：闪烁/呼吸周期

     - 单位：ms

.. admonition:: 参数说明
   :class: note

   - **power_mode**：供电方式

     - 0：外接电源
     - 1：电池

   - **charge_state**：充电状态

     - 0：无效
