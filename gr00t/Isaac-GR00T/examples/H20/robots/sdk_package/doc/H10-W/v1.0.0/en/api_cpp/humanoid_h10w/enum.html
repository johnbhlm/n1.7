Enumerations and Joint Index

H10w Joint Index (int)

The jointIndex parameter is represented by int, with the following mapping:

  • 0: JOINT_INDEX_UNKNOWN

  • 1: L_ARM_JOINT1

  • 2: L_ARM_JOINT2

  • 3: L_ARM_JOINT3

  • 4: L_ARM_JOINT4

  • 5: L_ARM_JOINT5

  • 6: L_ARM_JOINT6

  • 7: L_ARM_JOINT7

  • 8: R_ARM_JOINT1

  • 9: R_ARM_JOINT2

  • 10: R_ARM_JOINT3

  • 11: R_ARM_JOINT4

  • 12: R_ARM_JOINT5

  • 13: R_ARM_JOINT6

  • 14: R_ARM_JOINT7

  • 15: HEAD_YAW

  • 16: HEAD_PITCH

  • 17: EMPTY_INDEX_1

  • 18: ELEVATOR_MOTOR

  • 19: EMPTY_INDEX_2

  • 20: EMPTY_INDEX_3

  • 21: EMPTY_INDEX_4

humanoid::h10w::CartIndex

enum class humanoid::h10w::CartIndex

Represents the enumeration type of tool center point in Cartesian coordinate system.

  • UNKNOWN_CART: Unknown tool center point

  • LEFT_ARM: Left arm tool center point

  • RIGHT_ARM: Right arm tool center point

  • TORSO: Torso tool center point
