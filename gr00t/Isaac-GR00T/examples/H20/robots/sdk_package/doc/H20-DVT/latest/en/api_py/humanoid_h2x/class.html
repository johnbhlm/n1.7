Note

Controller mode description

EnableController is used to select the robot command source: when enabled, the onboard controller takes over motion planning and motor command delivery; when disabled, the user writes motor commands directly through the low-level interface.

  • EnableController = true: Controller mode. Suitable for high-level motion control APIs such as H2xHighLevel; the controller continuously sends planned motion commands to the drivers for packaged capabilities such as speed, gait, and full-body motion. Do not write motor commands through low-level interfaces at the same time in this mode to avoid command-source conflicts.

  • EnableController = false: Low-level control mode. Suitable for direct motor control interfaces such as H2xLowLevel; the controller stops sending motion commands, and the user must ensure the control period, joint targets, torque/speed/position limits, and emergency-stop protection.

  • Important mode switching notes: Before calling high-level motion APIs, set the value to true and confirm it with isControllerEnabled; before calling low-level control APIs, stop high-level motion tasks first, then set the value to false. During switching, keep the robot in a stable support state and avoid multiple command sources controlling the same joint at the same time.

Note

Controller mode description

EnableController is used to select the robot command source: when enabled, the onboard controller takes over motion planning and motor command delivery; when disabled, the user writes motor commands directly through the low-level interface.

  • EnableController = true: Controller mode. Suitable for high-level motion control APIs such as H2xHighLevel; the controller continuously sends planned motion commands to the drivers for packaged capabilities such as speed, gait, and full-body motion. Do not write motor commands through low-level interfaces at the same time in this mode to avoid command-source conflicts.

  • EnableController = false: Low-level control mode. Suitable for direct motor control interfaces such as H2xLowLevel; the controller stops sending motion commands, and the user must ensure the control period, joint targets, torque/speed/position limits, and emergency-stop protection.

  • Important mode switching notes: Before calling high-level motion APIs, set the value to true and confirm it with isControllerEnabled; before calling low-level control APIs, stop high-level motion tasks first, then set the value to false. During switching, keep the robot in a stable support state and avoid multiple command sources controlling the same joint at the same time.
